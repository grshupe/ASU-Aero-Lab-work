# ASU-Aero-Lab-work
Measurement of Zero Lift Drag Coefficients for NACA 0012 and NACA 4412 Airfoils Using Wake Profile Analysis
MATLAB was used for all data analysis, computation, and visualization. 
Calibration and uncertainty for **ALL** equiptment was done in previous labwork. 
Hot-wire anemometer was used for velocity profile data. A precision lead-screw 
The power form of King's Law was used for conversion between measured voltage and plotting. 
Drag analysis was done using momentum-deficit methods in tandem with continuity and conservation laws. 
See appropriate figures and sample calculations included within the report.
